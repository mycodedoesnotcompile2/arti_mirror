# arti-rpcserver

arti-rpcserver: Removed crate. (Implementation of RPC server functionality in Arti)

This crate was part of Arti, a project to implement Tor in Rust.

The project continues, but this particular crate has been renamed to [`tor-rpcserver`].
This empty crate is published as a tombstone.
